# virtuaall — сайт-портфолио и продажа Telegram-ботов

Статический сайт без сборки: открыл `index.html` — и он работает.
Публикуется на GitHub Pages автоматически при пуше в `main`.

**Живая версия:** https://virtuaall1.github.io/site/

## Что где лежит

```
index.html          разметка
css/style.css       вся вёрстка и дизайн-система
js/content.js       ← ЦЕНЫ, УСЛУГИ, КОНТАКТЫ, ПЕРЕВОДЫ (правится только это)
js/app.js           логика: язык, GitHub API, анимации, фон
scripts/check.js    проверки перед деплоем
```

## Как поменять цены или услуги

Всё в `js/content.js`, разметку трогать не нужно.

```js
{
  id: 'shop',
  price: '$250+',        // '?' — покажет «цена по задаче»
  featured: true,        // метка «хит»
  uk: { name: '…', desc: '…', bullets: ['…'] },
  en: { name: '…', desc: '…', bullets: ['…'] }
}
```

Контакты — там же, в блоке `LINKS` наверху файла.

## Как добавить свои работы

Секция «Репозитории» тянет данные с GitHub сама, но боты и коммерческие
проекты обычно лежат в приватных репозиториях заказчика. Такие работы
добавляются вручную в массив `PROJECTS` (`js/content.js`) — они показываются
выше списка репозиториев:

```js
{
  year: '2026',
  link: 'https://t.me/имя_бота',   // необязательно
  uk: { name: '…', desc: '…', tags: ['aiogram', 'PostgreSQL'] },
  en: { name: '…', desc: '…', tags: ['aiogram', 'PostgreSQL'] }
}
```

Репозитории, которые не нужно показывать (например, сам сайт), перечисляются
в `HIDDEN_REPOS`. Нулевые счётчики (0 звёзд, 0 подписчиков) скрываются сами.

Важно: у каждой услуги, шага и вопроса должны быть **оба** языка (`uk` и `en`),
иначе проверки не пропустят деплой.

## Языки

Украинский и английский. Сайт определяет язык по локали браузера: украинская
или русская локаль → украинский, всё остальное → английский. Выбор
пользователя запоминается в `localStorage`, переключатель UA/EN — в шапке.

## Проверки

```bash
node scripts/check.js
```

Проверяет пропущенные переводы, битые якоря, наличие CSP, `rel="noopener"`
на внешних ссылках, отсутствие `innerHTML` и вес страницы. Запускается в CI —
если что-то сломано, сайт не публикуется.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Технические решения

- **Безопасность:** строгий CSP (`default-src 'none'`), данные из GitHub API
  попадают в DOM только через `textContent`, внешние ссылки с `noopener noreferrer`.
- **Скорость:** нет сборки и фреймворков в бандле; ответы GitHub API кэшируются
  в `sessionStorage` на 30 минут, чтобы не упираться в лимит 60 запросов/час;
  фоновая анимация останавливается на неактивной вкладке.
- **Анимации:** GSAP + ScrollTrigger и Lenis подключаются с CDN, но сайт
  полностью работает и без них — есть фоллбэк на IntersectionObserver.
- **Доступность:** skip-link, фокус-стили, `aria-expanded` на аккордеоне,
  полное отключение анимаций при `prefers-reduced-motion`.
