# Чеклист перед сдачей

Пройди сверху вниз. Если пункт не выполнен — почини, а не отмечай как исключение.

## Токены

- [ ] В проектном CSS нет ни одного произвольного hex — только `var(--ds-*)`
- [ ] Отступы взяты из шкалы `--ds-1 … --ds-32`, нет значений вроде `13px` или `27px`
- [ ] Скругления только из `--ds-r-*`
- [ ] Тени только из `--ds-sh-*`
- [ ] Не подключены внешние шрифты

Быстрая проверка:
```bash
grep -nE '#[0-9a-fA-F]{3,8}\b' project.css | grep -v 'apple-ds'
grep -nE ':\s*[0-9]+px' project.css | grep -vE '(1px|0px)'
```

## Тёмная тема

- [ ] На `<html>` стоит `ds-auto`, `ds-dark` или `ds-light`
- [ ] В `<head>` есть `<meta name="color-scheme" content="light dark">`
- [ ] Каждый экран проверен в обеих темах
- [ ] Текст поверх градиентов остаётся белым в обеих темах
- [ ] Нет захардкоженных `#fff` и `#000` там, где нужен токен

## Семантика и доступность

- [ ] Все кликабельные элементы — `<a>` или `<button>`, не `<div>`
- [ ] Один `<h1>` на страницу, заголовки идут по порядку без пропусков
- [ ] У кнопок-иконок есть `aria-label`
- [ ] У изображений осмысленный `alt` (декоративные — `alt=""`)
- [ ] Форма проходится Tab от начала до конца, фокус всегда виден
- [ ] Диалоги: закрытие по Escape, ловушка фокуса, возврат фокуса назад
- [ ] Минимальная цель касания 44×44px

## Адаптив

- [ ] 320px — ничего не выезжает за экран, нет горизонтального скролла
- [ ] 768px — сетки перестраиваются осмысленно
- [ ] 1440px — контент не растягивается в бесконечную строку
- [ ] Длинные слова и URL не ломают вёрстку
- [ ] На мобильном учтены безопасные зоны (`.ds-safe-bottom` у липких панелей)

## Производительность

- [ ] Нет слушателей `scroll` там, где хватает `IntersectionObserver`
- [ ] Анимируются только `transform` и `opacity`
- [ ] `will-change` отсутствует или обоснован замером
- [ ] У изображений заданы `width`/`height` или `aspect-ratio` — нет сдвига макета
- [ ] Тяжёлые секции ниже первого экрана помечены `.ds-defer`
- [ ] Изображения в webp/avif, ниже первого экрана — `loading="lazy"`

## Движение

- [ ] При включённом `prefers-reduced-motion` анимации гаснут (проверь в devtools:
      Rendering → Emulate CSS prefers-reduced-motion)
- [ ] Нет анимаций входа на каждой секции — это выдаёт шаблон
- [ ] Движение отвечает на действие пользователя, а не играет само

## Тексты

- [ ] Кнопки называют действие, а не «Отправить»
- [ ] Ошибки объясняют, что делать, а не только что сломалось
- [ ] Пустые состояния приглашают к действию
- [ ] Одно действие называется одинаково во всём интерфейсе
