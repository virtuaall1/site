Оверлеи

Модалка, нижняя шторка и тост. Закрываются по Escape и клику по фону, фокус не убегает наружу.

Как подключить

Один файл, без сборщика и зависимостей.

<html lang="ru" class="ds-auto">
<link rel="stylesheet" href="apple-ds.css">

Режимы темы

  • .ds-auto — следует системной настройке
  • .ds-dark — принудительно тёмная
  • .ds-light — принудительно светлая, перебивает .ds-auto

Перекрасить под клиента

Меняется одна переменная — вся система следует за ней:

:root{
  --ds-accent:#FF6B35;
  --ds-accent-hover:#E5551F;
  --ds-accent-soft:rgba(255,107,53,0.12);
}

Что уже учтено

  • Кольцо фокуса только для клавиатуры (:focus-visible)
  • Отключение анимаций по prefers-reduced-motion
  • Усиление контраста по prefers-contrast
  • Стили печати и безопасные зоны мобильных
  • content-visibility для длинных страниц — класс .ds-defer
