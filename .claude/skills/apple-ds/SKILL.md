# Apple DS — дизайн-система студии

Единая система для всех сайтов. Файл `assets/apple-ds.css` — источник истины.
Никогда не пиши стили с нуля, если задачу решает существующий класс.

## Порядок работы

1. **Скопируй CSS в проект.** Возьми `assets/apple-ds.css` из этого скилла и
   положи в статику проекта (`public/`, `static/`, `assets/css/` — что принято
   в этом репозитории). Не дублируй его содержимое в другие файлы.

2. **Подключи и задай тему** на корневом элементе:
   ```html
   <html lang="ru" class="ds-auto">
   <head>
     <meta name="color-scheme" content="light dark">
     <link rel="stylesheet" href="/assets/apple-ds.css">
   </head>
   ```
   `.ds-auto` — следовать системе, `.ds-dark` / `.ds-light` — принудительно.

3. **Собери страницу из готовых классов.** Полный список — в
   `references/components.md`. Прочитай его перед вёрсткой, если не помнишь
   точные имена классов.

4. **Перекрась под клиента**, если у проекта свой бренд — правь только три
   переменные, остальное подхватится:
   ```css
   :root{
     --ds-accent:#FF6B35;
     --ds-accent-hover:#E5551F;
     --ds-accent-soft:rgba(255,107,53,0.12);
   }
   ```

5. **Проверь результат** по чеклисту в `references/checklist.md` перед тем,
   как отдать работу.

## Каркас страницы

```html
<header class="ds-header">
  <div class="ds-container ds-header__inner">
    <a class="ds-brand" href="/">Бренд</a>
    <nav class="ds-nav"><a href="#">Раздел</a></nav>
    <button class="ds-btn ds-btn--primary ds-btn--sm">Действие</button>
  </div>
</header>

<main>
  <section class="ds-section">
    <div class="ds-container ds-stack ds-stack--lg">
      <h1 class="ds-display">Заголовок</h1>
      <p class="ds-lead">Подзаголовок в одно-два предложения.</p>
    </div>
  </section>

  <section class="ds-section ds-section--sunken">
    <div class="ds-container ds-grid">
      <div class="ds-card ds-stack">…</div>
    </div>
  </section>
</main>
```

## Жёсткие правила

**Никогда:**
- не пиши произвольные hex-цвета — только токены `var(--ds-*)`;
- не задавай отступы «на глаз» — шаг 4px через `--ds-1 … --ds-32`;
- не подключай Google Fonts и внешние шрифты — стек системный, он уже в `--ds-font`;
- не ставь `will-change` без замеренной причины;
- не делай интерактивные элементы из `div` — только `<a>` и `<button>`;
- не анимируй `width`, `height`, `top`, `left` — только `transform` и `opacity`;
- не убирай `outline` у focus-visible;
- не добавляй библиотеки (Tailwind, Bootstrap, UI-киты) — система самодостаточна.

**Всегда:**
- минимальная цель касания 44×44px для всего кликабельного;
- у кнопок-иконок — `aria-label`;
- у изображений — осмысленный `alt`;
- скругления только из шкалы `--ds-r-xs … --ds-r-2xl`;
- тени только из `--ds-sh-xs … --ds-sh-xl` — свои не сочиняй;
- для длинных страниц вешай `.ds-defer` на тяжёлые секции.

## Когда класса не хватает

Расширяй систему, а не обходи её. Новый компонент пиши в отдельном файле
проекта, но строй его на существующих токенах:

```css
.project-pricing-card{
  background:var(--ds-surface);
  border-radius:var(--ds-r-lg);
  padding:var(--ds-6);
  box-shadow:var(--ds-sh-md);
}
```

Если один и тот же компонент понадобился в третьем проекте — предложи
перенести его в `apple-ds.css` и обнови `references/components.md`.

## Эстетика

Система задаёт механику, а не избавляет от вкуса. Держи в голове:

- **Одна яркая точка на экран.** Градиентная плитка или hero-карточка —
  акцент, всё вокруг спокойное. Не делай градиенты на каждом блоке.
- **Воздух важнее плотности.** Между секциями `--ds-16` и больше.
- **Тени почти не видны.** Если тень заметна сама по себе — она слишком сильная.
- **Текст до 70 символов в строке.** `.ds-body` и `.ds-lead` уже ограничены.
- **Копирайтинг в интерфейсе — часть дизайна.** Кнопка называет действие
  («Сохранить изменения», не «Отправить»), пустое состояние зовёт что-то сделать.
