# Фото напоїв

Сюди кладуться вирізані фото — саме на них тримається весь макет.

| Файл | Позиція |
| --- | --- |
| `latte.png` | Плітка-лате |
| `matcha.png` | Матча-лате |
| `raspberry.png` | Малиновий раф |
| `cocoa.png` | Какао з зефіром |
| `citrus.png` | Цитрус-фільтр |

Вимоги:

- **PNG з прозорим тлом** — тло сторінки має просвічувати навколо склянки
- квадрат, ~1400×1400, склянка займає майже всю висоту
- знімати згори-збоку, на рівному світлі, без різких тіней під склянкою
- тінь малює сама сторінка (`filter: drop-shadow`), у файлі її бути не повинно

Поки файлу немає, на його місці показується пунктирна рамка з підписом —
сторінка не ламається, але й не вдає, що фото є.

Імена файлів задаються в `js/menu.js`, поле `photo`.
