# Пліткарка — сайт кав'ярні

Односторінковий сайт кав'ярні «Пліткарка» (м. Косів, вул. Шевченка, 46).

Оформлення взяте з **косівської кераміки** — того, чим Косів відомий:
зелена полива, тепла глина, вохра й марганець. Наскрізна форма — арка
з гравірованим контуром, зміщеним на пів кроку, як обведення на розписі.
Секції чергують поливу й глину, між ними — смужка розпису.

| Роль | Значення |
| --- | --- |
| Полива (шапка, події) | `#23402f` |
| Глина (світлі секції) | `#f4ede0` |
| Вохра (єдиний яскравий) | `#cf9a3a` |
| Марганець | `#6b3f22` |
| Чорнило | `#241a12` |
| Заголовки | Literata |
| Інтерфейс і текст | Golos Text |

> Демонстраційний проєкт. Тексти й фото зібрані з інстаграму кав'ярні
> @plitkarka_o.m — перед публікацією замініть на оригінали.

## Що всередині

- **Перемикач «У чашці»** — п'ять позицій, клік по картці або стрілки ← →
- **Кухня** — галерея десертів і сиропів
- **Події** — презентації книжок і благодійні дні
- **Де ми** — дві точки на Шевченка, графік, Instagram
- Темна тема, адаптив від 320 px, `prefers-reduced-motion`

## Що треба замінити перед запуском

| Що | Де | Чому |
| --- | --- | --- |
| Фото | `img/*.jpg` | зараз це кадри з сітки інстаграму, 393 px завширшки — для сайту потрібні оригінали |
| Час закриття | `index.html`, поля «Відчиняємось» | у сітці видно лише «з 08:00», коли зачиняєтесь — невідомо |
| Телефон | `index.html`, розділ «Де ми» | у профілі не було, тож поля немає |
| Ціни | — | навмисно немає ніде: вигадувати ціни кав'ярні не можна |
| Дата презентації | розділ «Події» | «15 травня, 17:00» — з афіші в сітці, оновіть під наступну подію |

## Фото для перемикача

Позиції задаються в `js/menu.js`:

```js
{
  id: 'cappuccino',
  name: 'Капучино',
  sub: 'з латте-артом, на столику надворі',
  photo: 'img/cappuccino.jpg',
  glow: '#a79662'   // тон світла за фото
}
```

`glow` — світлий відтінок самого знімка. Найпростіше взяти піпеткою
середній колір фото й трохи підняти яскравість.

Формат фото: вертикаль приблизно 4:5, від 1200 px завширшки.

## Стек

Чистий HTML, CSS і JavaScript. Без збірки й залежностей.

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

Шрифти: Nunito (заголовки) і Onest (текст).
