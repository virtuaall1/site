# Пліткарка — сайт кав'ярні

Односторінковий сайт кав'ярні в Косові (дві точки на вул. Шевченка).

> Демонстраційний проєкт. Тексти, меню й фото зібрані з профілю
> @plitkarka_o.m — перед публікацією замініть фото на оригінали
> й проставте ціни.

## Оформлення

Кейс зібраний на спільній системі `cases/_ui/ui.css`: капсули, білі
картки на теплому сірому, велика пастельна арка й заголовок у два
голоси — капс гротеском, друга строка курсивним серифом. Своє тут
лише персикова пастель `#f7d6c2` і кілька розкладок.

Меню перемикається вкладками, афіша — рідними `<details>`.

## Ціни

У профілі кав'ярні цін не було, тому в `js/menu.js` вони стоять як
`null`, а сторінка показує риску. Проставте число — і риска зникне:

```js
{ id: 'cappuccino', name: 'Капучино', note: 'з латте-артом',
  photo: 'img/cappuccino.jpg', price: 55 }
```

Вигадувати ціни чинній кав'ярні не можна, тому вони й лишились порожні.

## Схема вулиці

У розділі «Дві точки» — не мапа, а схема: точних координат ми не
знаємо, тому малюнок показує порядок (центр → гімназія → Шевченка, 46),
а не відстані. Так і підписано під схемою.

## Запуск

```bash
python3 -m http.server 8000
```

Чистий HTML, CSS і JavaScript. Без збірки й залежностей.
