# Пліткарка — сайт кав'ярні

Односторінковий сайт кав'ярні в Косові (дві точки на вул. Шевченка).

> Демонстраційний проєкт. Тексти, меню й фото зібрані з профілю
> @plitkarka_o.m — перед публікацією замініть фото на оригінали
> й проставте ціни.

## Ідея оформлення

Стрижень — **світло**. Поки гортаєш сторінку, тло теплішає від
ранкового фарфору до денного, а акцент глибшає; угорі йде тонка смуга
дня і міняється підпис «Зранку → Вдень → Пополудні → Увечері».

Вечір приходить не плавним перетіканням, а **окремими розділами**
з власною темною палітрою. Це навмисно: якщо тягнути світле тло
в темне лінійно, десь посередині виходить сіра каша, у якій текст
перестає читатися.

| Роль | Значення |
| --- | --- |
| Ранок | `#eceeeb` тло, `#191a17` текст |
| День | `#e9e0d3` тло, акцент `#8c2f44` |
| Вечір (розділи) | `#1e1712` тло, акцент `#e88aa0` |
| Заголовки | Literata |
| Мітки часу | Oswald |
| Текст | Manrope |

## Взаємодія

- наведення на позицію меню міняє знімок поруч (клік — на телефоні)
- смуга дня вгорі показує, наскільки далеко зайшла сторінка
- мітка часу зліва липне, поки читаєш розділ
- `prefers-reduced-motion` зупиняє світло на ранньому дні

## Ціни

У профілі кав'ярні цін не було, тому в `js/menu.js` вони стоять як
`null`, а сторінка показує риску. Проставте число — і риска зникне:

```js
{ id: 'cappuccino', name: 'Капучино', note: 'з латте-артом',
  photo: 'img/cappuccino.jpg', price: 55 }
```

Вигадувати ціни чинній кав'ярні не можна, тому вони й лишились порожні.

## Схема вулиці

У розділі «Дві точки» — не мапа, а схема: точних координат ми не
знаємо, тому малюнок показує порядок (центр → гімназія → Шевченка, 46),
а не відстані. Так і підписано під схемою.

## Запуск

```bash
python3 -m http.server 8000
```

Чистий HTML, CSS і JavaScript. Без збірки й залежностей.
