# Кейси

Демонстраційні сайти студії. Лежать усередині основного репозиторію
навмисно: GitHub Pages віддає його цілком (`path: .` у `pages.yml`),
тож кожна тека одразу стає живим посиланням і не потребує окремого
репозиторію та окремого деплою.

| Тека | Живе посилання | Що показує |
| --- | --- | --- |
| `orbita/` | `/site/cases/orbita/` | вебзастосунок з адмінкою: заявки, ролі, виторг |
| `plitkarka/` | `/site/cases/plitkarka/` | сайт кав'ярні в Косові |
| `shop-bot/` | `/site/cases/shop-bot/` | Telegram-бот магазину, який можна пройти в браузері |

Посилання на них стоять у `js/content.js`, масив `PROJECTS`.

## Спільна система

`_ui/ui.css` — одна мова оформлення на всі кейси: капсульні кнопки,
білі картки на теплому сірому, велика пастельна арка, лаймовий акцент
і заголовок у два голоси (капс гротеском, друга строка курсивним
серифом). Кейс підключає її перед власним `css/style.css` і
перевизначає лише `--pastel`:

| Кейс | Пастель |
| --- | --- |
| Орбіта | `#bfc9f7` барвінковий |
| Пліткарка | `#f7d6c2` персиковий |
| Магазин | `#c9e8d4` мʼятний |

Так три сайти читаються як роботи однієї студії, але кожен лишається
впізнаваним. Шрифти теж спільні: Onest (капс), Literata курсивом
(друга строка заголовка), Golos Text (текст), JetBrains Mono (числа).
