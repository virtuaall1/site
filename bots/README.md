# Боты

Три рабочих бота на aiogram 3 и SQLite. Каждый запускается одной
командой и не требует ничего, кроме токена от [@BotFather](https://t.me/BotFather).

| Папка | Что делает |
| --- | --- |
| `booking/` | запись к мастеру: окна, напоминания, лист ожидания, отчёты |
| `spend/` | учёт расходов: «120 кава» одной строкой, лимиты, недельный итог |
| `guard/` | модератор чата: капча, антиспам, лестница наказаний |

## Запуск

```bash
cd bots/booking
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
BOT_TOKEN=сюди_токен python3 bot.py
```

Настройки — через переменные окружения, образец в `.env.example`
рядом с каждым ботом. Свой Telegram-id (для `BOT_OWNERS`) узнаётся
у [@userinfobot](https://t.me/userinfobot).

Боту-модератору нужны права администратора в чате: удалять
сообщения и ограничивать участников. Остальным двум ничего не нужно.

## Проверки

Логика, которую можно проверить без телеграма, вынесена в отдельные
модули и покрыта тестами. Запускаются просто как файлы:

```bash
python3 bots/booking/test_slots.py    # расчёт свободных окон
python3 bots/spend/test_parse.py      # разбор «120 кава»
python3 bots/guard/test_rules.py      # правила модерации
```

Тесты не для галочки: в модераторе они поймали настоящую ошибку.
Текст приводился к «латинице», чтобы ловить обход фильтра через
похожие буквы, — но словарь оставался кириллическим, и фильтр
переставал видеть даже честный спам.

## Почему SQLite, а не «нормальная» база

Для салона на три кресла, личного учёта и чата на пару тысяч человек
SQLite быстрее любой сетевой базы: нет сети между приложением и
данными. Обслуживать нечего, бэкап — это скопировать один файл.
Когда нагрузка вырастет настолько, что это станет мало, у проекта
уже будет бюджет на переезд.

## Деньги и время

Суммы везде хранятся в копейках целыми числами. `0.1 + 0.2` в
дробных числах даёт `0.30000000000000004`, и на сотой операции отчёт
перестаёт сходиться с кассой.

Время хранится строками ISO в местной зоне. Зона задаётся один раз в
настройках; сравнения работают лексикографически, потому что ISO
для этого и придуман.
