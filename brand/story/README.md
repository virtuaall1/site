П'ять сегментів по 15 секунд — рівно стільки триває один кадр
історії в інстаграмі. Разом виходить хвилина, і їх можна викласти
підряд: кожен наступний починається там, де скінчився попередній.

| файл | про що | що робиться на екрані |
|---|---|---|
| `st-1-open.mp4`    | перший екран | три броски пальцем униз |

## Головне про ці ролики

Усередині рамки телефона — **не картинка, а сам сайт**. Він
відкритий в `iframe`, гортається по-справжньому і по-справжньому
реагує на натискання: перемикач валюти справді перераховує ціни,
кнопка теми справді перефарбовує сторінку. Тому ролик не треба
перемальовувати, коли сайт змінюється — досить перезняти.

Шрифти теж справжні. Сайт бере `Unbounded` і `Onest` з гугла, з
пісочниці туди не пройти, тому файли лежать у `fonts/` і
підставляються на льоту. Сам сайт при цьому не міняється ні на
рядок.

## Як перезняти

```bash
NODE_PATH=/tmp/node_modules node brand/story/render.js            # усі п'ять
NODE_PATH=/tmp/node_modules node brand/story/render.js st-3-price # тільки один
python3 brand/story/sound.py                                      # накласти звук
```

`render.js` сам піднімає локальний сервер (з `file://` iframe не
пускає до свого документа) і сам його гасить. Кадри знімаються
покадрово через `setT(0…1)`, тому два прогони дають однаковий
результат.

## Якщо вёрстка поїхала

Усі числа в `scenes.js` — координати справжньої сторінки при вікні
390×690. Коли на сайті з'явиться новий блок, координати з'їдуть.
Перезамірити:

```js
// у консолі сайта при вікні 390×690
document.querySelector('#curSwitch').getBoundingClientRect().top + scrollY
```

Камера завжди наїжджає на середину телефона, а потрібний блок під
неї підводить прокрутка: елемент із координатою `py` опиняється в
центрі кадру при `scroll = py − 368`.

## Чого тут немає

- **Курс НБУ і дані з GitHub** у пісочниці не тягнуться — мережу
  туди закрито. На екрані видно запасні значення, які сайт показує
  без інтернету. На живому сайті числа справжні.
- **Адреса `vstudio.dev`** написана в рядку Safari тому, що так
  вирішено на сайті. Поки домен не прив'язаний, це домовленість, а
  не факт — коли прив'яжуть, нічого міняти не треба.
