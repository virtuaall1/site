# Шпалери v.studio

Готові файли — в `out/`. Три сюжети × пʼять розмірів.

| сюжет | що це |
|---|---|
| `mesh` | мʼяке кольорове світло по темному |
| `flow` | тисячі тонких ліній, що течуть полем |
| `grid` | точна сітка й одна акцентна дуга — найспокійніший |

| розмір | під що |
|---|---|
| `desktop-1920x1080` | Full HD монітор |
| `desktop-3840x2160` | 4K монітор |
| `phone-1080x1920` | телефон Full HD |
| `phone-1179x2556` | iPhone 15 (рідна роздільність) |
| `phone-2160x3840` | телефон 4K |

На телефонних розмірах підпису немає: його все одно закриють іконки.

## Перезняти

```bash
NODE_PATH=/tmp/node_modules node brand/wallpaper/render.js         # усі
NODE_PATH=/tmp/node_modules node brand/wallpaper/render.js flow    # один сюжет
WALL_ACCENT='#35E0A1' NODE_PATH=/tmp/node_modules node brand/wallpaper/render.js
```

Кожен розмір креслиться під свою кількість пікселів, нічого не
масштабується — тому 4K справді 4K, а не розтягнутий Full HD.

Малюнок керовано випадковий: `?seed=` в адресі. Той самий seed завжди
дає той самий кадр, тож шпалеру можна перезняти й отримати ту саму.

## Подивитись у браузері

`brand/wallpaper/index.html?v=flow&w=1920&h=1080&a=%23FF7A45&mark=1`
