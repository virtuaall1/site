# Оформлення Instagram — v.studio

Макети зроблено в тих самих токенах, що й сайт: ink `#0a0a0b`,
папір `#f2efe8`, кислотний акцент `#d8ff3e`, шрифти Unbounded і Onest.
Правила два:

1. **Один кислотний акцент на кадр** — решту тримають лінійки,
   сітка точок і кутові мітки.
2. **Крапка з назви — робочий елемент, а не прикраса.** Вона є в знаку
   («v.»), стоїть у кінці великих заголовків і в плашці заклику.
   У Unbounded крапка квадратна, тому вона збігається за формою
   з акцентними блоками на сайті.

Контакт у макетах лишається особистим — `@virtuaall01`. Назва студії
стоїть як підпис, і це різні речі: підпис каже, хто зробив, контакт —
куди писати.

## Роздільність

`render.js` знімає кожен макет **у потрійному розмірі** й аж потім зменшує
до того, який чекає Instagram. Так тонкі лінійки, кутові мітки й кільце
лишаються різкими: браузер малює їх по три пікселі на кожен, а зменшення
усереднює. Знімок одразу в 1080 давав рвані краї.

Оригінали 3× лежать у `png/3x/` — для сайту, Telegram і друку,
де 1080 замало.

На аватарі й обкладинках немає сітки точок: вони живуть у 40–110 px,
і сітка там перетворюється на шум. Кільце на них товсте (12 px і 8 px),
бо тонке на такому розмірі просто зникає.

## Як правити

Увесь текст — у `kit.html`, звичайною розміткою. Поміняв слова,
перерендерив:

```bash
npm i playwright-core
CHROME_PATH=/шлях/до/chrome node brand/instagram/render.js
```

PNG складаються в `brand/instagram/png/`. Якщо додаєш новий макет —
дай йому `id` і впиши цей `id` у масив `BOARDS` у `render.js`.

## Відео

`motion.html` — це сторіс, які вміють рухатись. Сцена вибирається
адресою: `?scene=chat`, `?scene=dots` і так далі. Час у них не йде
сам: рендер каже сторінці `setT(0…1)` і знімає кадр. Тому ролик
виходить рівний, навіть коли машина гальмує, і повторний рендер дає
той самий файл до кадру — розкид точок у сцені `dots` теж не
випадковий, а рахується від координат.

У кожного ролика своя механіка, а не свій текст:

| Сцена | Що відбувається |
| --- | --- |
| `intro` | марка збирається, далі три напрямки і контакт |
| `cases` | три справжні знімки кейсів по черзі |
| `chat` | переписка в Telegram: замовлення без менеджера |
| `terminal` | лог набирається по буквах, з курсором |
| `price` | розклад ціни на три частини, підсумок докручується |
| `flow` | лінія їде вниз і запалює чотири кроки |
| `stack` | плашки залітають хвилею, головні лишаються |
| `type` | рядки підміняють один одного на місці |
| `counter` | три числа докручуються від нуля |
| `checklist` | галочки домальовуються штрихом |
| `wipe` | три послуги витирають одна одну на весь кадр |
| `dots` | сітка точок збирається у знак «v.» |

Знак у `dots` не намальований координатами: сцена малює літеру
шрифтом на невидимому полотні і питає, які вузли сітки в неї
потрапили. Зміниться шрифт — зміниться і знак, розходження неможливе.

```bash
CHROME_PATH=/шлях/до/chrome FFMPEG_PATH=/шлях/до/ffmpeg \
  node brand/instagram/render-video.js            # усі дванадцять
  node brand/instagram/render-video.js chat dots  # тільки названі
```

Виходить `video/*.mp4` — H.264, 1080×1920, 30 кадрів, 6 секунд, без
звуку. Instagram такі приймає і в сторіс, і в Reels; для Reels згори
варто накласти музику вже в застосунку.

Кадри знімаються у півтора рази більшими й зменшуються в ffmpeg —
інакше тонкі лінійки й кутові мітки на відео сипляться.

## Звук

Ролики озвучены, и звук синтезируется, а не берётся из библиотеки —
чтобы попадать ровно в события сцены.

Тайминги в `motion.html` лежат числами внутри функций сцен.
Переписать их в таблицу для звука значило бы завести второе место,
которое разъедется при первой правке. Поэтому `timing.js` не
переписывает, а **замеряет**: прогоняет сцену по 360 шагам и
записывает, когда что произошло на самом деле — элемент проявился
(`pop`), сменился текст (`tick`), поехала шторка (`whoosh`).
Поменяется анимация — тайминги пересчитаются сами.

`sound.py` решает только одно: чем каждое событие звучит. У сцен
разные механики, поэтому один и тот же `pop` звучит по-разному —
иначе двенадцать роликов звучали бы одинаково, а они и сделаны
затем, чтобы не быть одинаковыми:

| Сцена | Голос |
| --- | --- |
| `chat` | пузырь, свои и чужие сообщения разной высоты |
| `terminal` | щелчки клавиш — 72 штуки, по набору |
| `price` `counter` | накрутка числа мелкими бликами, в конце удар |
| `stack` | сухие щелчки, высота растёт по волне |
| `cases` | затвор — так читается смена снимка |
| `checklist` | светлый тик, будто галочку прочертили |
| `wipe` | шорох на каждую шторку |
| `dots` | россыпь бликов, пока точки слетаются, и аккорд, когда знак загорелся |

Пик −4 dBFS, тише чем в TikTok: сторис часто смотрят без звука, и
подложка не должна лезть вперёд картинки.

```bash
node brand/instagram/timing.js        # снять моменты событий
python3 brand/instagram/sound.py      # вшить дорожку
```

Дорожка вшивается без пересжатия картинки (`-c:v copy`) — секунды,
а не минуты. Пересобирать видео ради звука не нужно.

## Про тексти

У макетах стоять реальні послуги й ціни з `js/content.js`: сайт від
₴3 500, бот з оплатою від ₴7 000, бекенд від ₴9 000, вебзастосунок
від ₴11 000. Міняються ціни на сайті — міняй і тут, інакше профіль
почне обіцяти інше.

Валют дві. Головна — гривня: замовник в Україні думає в гривні й
не має рахувати курс сам. Долар іде другим рядком дрібним, бо
гривнева ціна за півроку поповзе, а доларова — ні.

На сайті долар рахується сам, за курсом НБУ на сьогодні. У макетах
так не вийде — картинка не вміє ходити в мережу, тому долар у ній
завжди знімок: перерахований по 45 ₴/$ (рівне число трохи вище
курсу НБУ ≈ 44,6 у вересні 2026). Курс поїде відчутно — просто
перерендер, і числа підтягнуться.

Три кейси — це справжні роботи, які відкриваються за посиланням, і на
сторіс стоять їхні реальні знімки з `img/cases/`. Термінів у макетах
немає навмисно: жоден із них не заміряний, а називати цифру, яку не
перевіриш, — найшвидший спосіб посваритися з першим же клієнтом.
