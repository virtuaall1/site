# Аватарки

Один макет — `index.html` — и несколько размеров из него.

```
npm run avatars
```

Кладёт в `png/`:

| файл | размер | куда |
| --- | --- | --- |
| `telegram.png` | 512 | аватарка бота `@vstudiodev_bot` и канала |
| `instagram.png` | 1080 | профиль в Instagram |
| `github.png` | 460 | профиль на GitHub |
| `apple-touch-icon.png` | 180 | иконка сайта на рабочем столе iPhone |

Последняя заодно копируется в `img/` — её отдаёт сам сайт, остальные
ставятся руками в настройках площадок.

Почему так:

- **Снимается вдвое крупнее и уменьшается.** Сетка точек и кромка
  буквы в 460 пикселей иначе выходят рваными: браузер рисует точку
  в один пиксель и округляет, как выйдет.
- **По углам ничего нет.** Телеграм и инстаграм режут аватарку в
  круг, гитхаб — в квадрат со скруглением. Рамки по краю нет по той
  же причине: в круге от неё осталось бы четыре дуги.
- **Квадрат стоит на базовой линии буквы**, а не по центру — так
  читается «v.», а не «v ■». Его туда сажает сам шрифт, вручную
  ничего не двигаем.
