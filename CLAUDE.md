# Как работать в этом репозитории

## Оформление: дизайн-система apple-ds

Главная страница собрана на **`css/apple-ds.css`** — это дизайн-система
студии, лежит скиллом в `.claude/skills/apple-ds/` и оттуда же
скопирована в проект. Скилл — источник истины: там токены, список
готовых классов (`references/components.md`) и чеклист сдачи
(`references/checklist.md`). Читай его перед любой правкой вёрстки.

`css/style.css` — тонкий проектный слой поверх системы. В нём **нет
ни одного своего hex-цвета и ни одного отступа «на глаз»**: всё через
`var(--ds-*)`. Единственные исключения помечены комментарием на месте
(белый на красной карточке-призыве — она красная в обеих темах).

**Фирменная палитра** живёт в разделе 00 `style.css` и переопределяет
токены системы: тёмная винная база, красный акцент, тёплые нейтрали.
Три блока (`:root`, медиазапрос, `.ds-dark`) — не дублирование, а то,
как система читает тему; правь все три сразу.

Акцентов два: `--ds-accent` для заливок (тёмный красный, чтобы белая
надпись читалась) и `--v-accent-text` для текста (светлее, чтобы
читался на чёрном). Не путать.

**Тему** ставит `applyTheme` в `js/app.js`: классы `ds-light` / `ds-dark`
на `<html>` плюс прежний `data-theme` (его ещё читают кейсы).

**Шрифт системный.** Google Fonts отключены намеренно — так требует
система и так быстрее. `Unbounded` и `Onest` из вёрстки убраны, из CSP
тоже.

**Чего не делать.** Кислотный `#d8ff3e` — старая палитра студии, не
тащить. Градиенты на каждом блоке: яркая точка на страницу одна —
карточка контакта. Тени сочинять не надо, только `--ds-sh-*`.

## Живой сайт: правило про подтверждение

Оформление меняется **только когда попросили прямо**. Просьба
«сделай в таком стиле» с картинкой — это просьба показать, а не
выкатить, пока не сказали «нужен сайт с таким оформлением».

Так уже дважды выходило: капсульный редизайн откатывали, первый заход
в стиль Apple — тоже.

Чужие макеты с Pinterest и дрибббла один в один не повторяем: берём
направление (палитру, скругления, плотность), а не чужую работу.

## Что ещё не переведено

**Кейсы (`cases/*`) остались в прежнем оформлении** — их переводить
отдельной задачей. Ролики в `brand/story/` сняты с прежнего сайта:
после редизайна их надо переснять (`node brand/story/render.js`).

## Что важно помнить про проект

- Сайт публикуется **Cloudflare** из этого репозитория, а не GitHub
  Pages. Workflow GitHub Actions удалён намеренно: он слал лишние
  уведомления. Проверки живут в `npm run build`.
- Команда сборки в панели Cloudflare — `npm run build`, каталог —
  `dist` (задан в `wrangler.jsonc`).
- Адрес сайта подставляется переменной `SITE_URL` при сборке. В
  исходниках он записан как GitHub Pages — так и должно быть.
- Деньги везде хранятся в копейках целыми числами.
- Тексты на сайте украинские, комментарии в коде — русские.
- Ничего не выдумывать: цены, сроки и отзывы берутся из реальных
  данных или не пишутся вовсе.
