# Как работать в этом репозитории

## Оформление — в стиле Apple

Постоянное требование владельца: **почти всё оформление делать в стиле
Apple / iOS**. Это касается новых страниц, кейсов, макетов и роликов.
Уже существующие вещи не переделывать без отдельной просьбы — сайт
студии однажды уже пересобирали и откатывали.

Стиль — не «скруглить углы», а конкретный набор решений.

**Шрифт.** Сначала системный, потом запасной:
`-apple-system, BlinkMacSystemFont, 'SF Pro Display', Inter, system-ui, sans-serif`.
На технике Apple это настоящий San Francisco, на остальном — Inter,
который под него и рисовали. Крупным кеглям нужен минусовой трекинг
(−0.02…−0.03em), мелким — нулевой.

Шкала как в iOS, без промежуточных размеров:
34 / 28 / 22 / 20 / 17 полужирный / 17 / 15 / 13 / 12.
Основной текст — 17, а не 16: на телефоне это заметно.

**Цвет.** Нейтрали серые, а не бежевые. Светлая тема: фон групп
`#F2F2F7`, карточки `#FFFFFF`, разделители `rgba(60,60,67,.29)`,
вторичный текст `#3C3C4399`. Тёмная: фон `#000`, карточки `#1C1C1E`,
разделители `rgba(84,84,88,.65)`.

Акцент один — синий `#007AFF` (в тёмной `#0A84FF`). Смысловые цвета
отдельно от акцента: успех `#34C759`, предупреждение `#FF9F0A`,
ошибка `#FF3B30`. Кислотный `#d8ff3e` — это старая палитра студии,
в новом оформлении её не тащить.

**Поверхности.** Карточки со скруглением 12–22 px (чем крупнее блок,
тем больше), тень мягкая и почти незаметная:
`0 1px 3px rgba(0,0,0,.06), 0 8px 24px rgba(0,0,0,.05)`. Панели и
шапки — полупрозрачные с размытием (`backdrop-filter: blur(20px)
saturate(180%)`), потому что именно это читается как iOS, а не
скругления.

Списки — сгруппированные: карточка с внутренними разделителями,
которые не доходят до левого края, а начинаются от текста.

**Движение.** Пружинное, не линейное: `cubic-bezier(0.32, 0.72, 0, 1)`,
0.3–0.5 с. Нажатие даёт `scale(0.97)`. Всё выключается при
`prefers-reduced-motion`.

**Чего не делать.** Градиентных заливок «из фиолетового в синий»,
неона, толстых чёрных обводок, декоративных засечек, теней-«коробок».
Пустое место — часть оформления, а не то, что надо заполнить.

## Что важно помнить про проект

- Сайт публикуется **Cloudflare** из этого репозитория, а не GitHub
  Pages. Workflow GitHub Actions удалён намеренно: он слал лишние
  уведомления. Проверки живут в `npm run build`.
- Команда сборки в панели Cloudflare — `npm run build`, каталог —
  `dist` (задан в `wrangler.jsonc`).
- Адрес сайта подставляется переменной `SITE_URL` при сборке. В
  исходниках он записан как GitHub Pages — так и должно быть.
- Деньги везде хранятся в копейках целыми числами.
- Тексты на сайте украинские, комментарии в коде — русские.
- Ничего не выдумывать: цены, сроки и отзывы берутся из реальных
  данных или не пишутся вовсе.
